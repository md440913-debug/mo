إعدادات الربط السحابي (Firebase Realtime)

لحفظ البيانات سحابياً والعمل المشترك بينك وبين زملائك لحظياً

كيف تحصل على إعدادات Firebase الخاصة بك؟
  1. افتح موقع console.firebase.google.com وسجل بحساب Google.
  2. اضغط Add project واكتب اسم المشروع (مثال: Garment-Cuts-ERP).
  3. من القائمة الجانبية اختر Realtime Database ثم Create Database واختر Start in Test mode.
  4. من إعدادات المشروع (Project Settings) > General > Apps > أضف Web App وافرغ كود firebaseConfig هنا.

تأكد من وجود رابط databaseURL في الإعدادات ليعمل الـ Realtime Database بنجاح.
